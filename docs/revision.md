# Ревизия исходного шаблона

| Файл и строка | Дефект | Последствие | Исправление |
|---|---|---|---|
| Dockerfile 1 | FROM python:latest | Непредсказуемая версия Python и лишняя загрузка вместо уже используемой базы | FROM python:3.12-slim |
| Dockerfile 5 | COPY . . до установки зависимостей | Любое изменение app.py инвалидирует pip install | Сначала COPY requirements.txt и RUN pip, затем COPY app.py |
| Dockerfile 5 и отсутствие .dockerignore | В контекст попадают .env и .git | Секреты и история могут оказаться в слоях образа | Исключить .env и .git; копировать только нужные файлы |
| Dockerfile после RUN | Отсутствует USER | Уязвимость приложения выполняется с UID 0 контейнера | Создать системного app и USER app |
| Dockerfile 9 | CMD в shell-форме | PID 1 получает оболочка; SIGTERM может не дойти до gunicorn | Exec-форма JSON массива |
| Dockerfile 9 | bind 127.0.0.1 внутри контейнера | Пакеты через опубликованный порт приходят на интерфейс контейнера и не принимаются loopback-сокетом | bind 0.0.0.0:8002 |
| Dockerfile 8 и 9 | Порт 8000 не соответствует варианту | Конфигурация публикации 8002:8002 не достигает приложения | EXPOSE 8002 и gunicorn на 8002 |
| Отслеживаемый .env | Пароль хранится в Git | Получатели репозитория читают секрет в истории | git rm .env, .gitignore, .env.example; новый пароль только на сервере |
